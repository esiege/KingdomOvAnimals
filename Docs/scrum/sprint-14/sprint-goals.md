# Sprint 14 Goals

*(planned 2026-08-12, not yet started)*

## Primary Goal

**Make the two-type deck blend — the core replayability hook of the whole pitch — legible to the player, not
just a side effect of the data model.**

## Success Criteria

By the end of this sprint, we should have:

1. [ ] Deck viewer visually distinguishes cards by originating type (Story 051)
2. [ ] Deck composition (type balance, mana curve) visible at any point during the run
3. [ ] New second-type cards called out distinctly when first added post-Board-1

## Key Focus Areas

### 1. This Is a UX Sprint, Not a Systems Sprint
The mixing already works mechanically by Sprint 09; this sprint is entirely about whether players can *see and
understand* their build as it forms.

## Non-Goals (Out of Scope)

- Any new deck-building mechanics beyond what Sprint 09/13 already established
- AI-generated mutation cards (Sprint 15 — related idea, separate system)

## Definition of Done for Sprint

- [ ] A player can explain their deck's type composition at a glance, at any point in a run
