# Sprint 16 Goals

*(planned 2026-08-12, not yet started)*

## Primary Goal

**Make the full run loop ready for real players — matchmaking that holds up, and a balance/bug pass — before
adding any new scope.**

## Success Criteria

By the end of this sprint, we should have:

1. [ ] Sprint 07's matchmaking spike hardened against realistic load and edge cases (Story 053)
2. [ ] Full playtesting across multiple complete runs, both starter types, both win and loss paths (Story 054)
3. [ ] Card/ability balance review across all type card pools introduced since Sprint 09
4. [ ] A bug bash covering the full 10-duel run loop, not just individual duels

## Key Focus Areas

### 1. Polish, Not Features
This sprint is intentionally scoped as "no new feature work" — see Story 054. It's the natural point to decide
whether to keep building (see the post-Sprint-16 themes in `Docs/scrum/backlog.md`: dedicated servers, ability
depth, meta-progression, content tooling, anti-cheat) or ship what exists.

## Non-Goals (Out of Scope)

- Any new feature work
- Post-Sprint-16 themes (dedicated servers, meta-progression, etc.) — deliberately left unscoped until this
  sprint's findings inform what actually needs attention

## Definition of Done for Sprint

- [ ] No known critical bugs across a full run
- [ ] Matchmaking behaves acceptably under realistic concurrent load
- [ ] Balance pass complete and documented
