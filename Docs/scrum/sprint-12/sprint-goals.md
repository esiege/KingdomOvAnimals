# Sprint 12 Goals

*(planned 2026-08-12, not yet started)*

## Primary Goal

**Give the run a climax and an ending — Board 3's capstone content and the victory/defeat flow.**

## Success Criteria

By the end of this sprint, we should have:

1. [ ] Board 3's 3 segments have distinct, non-type-themed content (Story 049)
2. [ ] Wildcard/hybrid card rewards on Board 3, different from type-themed rewards
3. [ ] Victory screen on winning the 10th (final boss) duel (Story 050)
4. [ ] Defeat screen on reaching 0 lives at any point
5. [ ] Player can start a new run after either ending

## Key Focus Areas

### 1. Board 3 Distinctness
Board 3 isn't tied to either of the player's two types — it should feel like a deliberate finale, not "board 3
of 3" with the same content pattern as 1 and 2.

### 2. Clean Run Boundaries
A run needs an unambiguous end state either way (win or 0 lives) that returns the player to a fresh start.

## Non-Goals (Out of Scope)

- Rewards/unlocks/leaderboards beyond the run itself — that's a post-Sprint-16 meta-progression theme, not
  scoped into stories yet (see `Docs/scrum/backlog.md`)

## Definition of Done for Sprint

- [ ] A full run can be completed start-to-finish via both victory and 0-lives defeat, manually tested
