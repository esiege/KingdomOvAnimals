# Story 050: Run Completion Flow

## Status: Not Started
## Sprint: 12
## Dependencies: 046, 048, 049
## Created: 2026-08-12

## User Story
**As a** player
**I want** a clear ending when I win or lose my run
**So that** I know the run is over and can start a new one

## Acceptance Criteria
- [ ] Winning the final boss duel (the 10th duel) shows a victory screen and ends the run
- [ ] Reaching 0 lives at any point shows a defeat screen and ends the run
- [ ] Player is returned to a state where they can start a new run (new starter type selection)
- [ ] Manual test: complete a full run start-to-finish both via victory and via 0-lives defeat

## Notes
Deliberately minimal scope — rewards/unlocks/leaderboards are out of scope here, see the post-Sprint-16 "meta
layer" discussion in `Docs/scrum/backlog.md`.
