# Sprint 15 Goals

*(planned 2026-08-12, not yet started)*

## Primary Goal

**Find out — cheaply — whether AI-generated hybrid "mutation" cards are a viable feature, without committing to
shipping them.**

## Success Criteria

By the end of this sprint, we should have:

1. [ ] A feasibility spike: can generation produce mechanically-valid `CardData`-shaped output (name, cost,
      health, ability references) without manual cleanup? (Story 052)
2. [ ] Balance guardrails tested (constrained stat/cost ranges relative to existing cards)
3. [ ] A written finding: viable for real content, or needs a curated-template fallback instead

## Key Focus Areas

### 1. This Is a Spike, Not a Feature Sprint
Explicitly out of scope: shipping this live. The point is a go/no-go decision with evidence behind it.

## Non-Goals (Out of Scope)

- Shipping AI-generated cards as a live feature
- Polishing generation quality beyond "enough to judge feasibility"

## Definition of Done for Sprint

- [ ] A written recommendation exists on whether to pursue this further, backed by actual generated examples

## Note

This is the easiest sprint in the whole plan to cut or slip if 05-14 run long — nothing downstream depends on it.
