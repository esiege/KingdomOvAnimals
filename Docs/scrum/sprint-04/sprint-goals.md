## Why It Was Retired

The original plan assumed a player-chosen second class, a 2-board + loosely-sized "endgame" structure, and no
mention of a live-PvP-only constraint. The current pitch (3 boards × 3 segments + boss = 10 duels, no NPC
fallback, random second type) changes enough of the shape that continuing to plan against this file would have
been misleading. See `Docs/game-design/adventure-mode.md`'s "Open Tensions" section for what's still undecided.
