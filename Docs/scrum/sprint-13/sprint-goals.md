# Sprint 13 Goals

*(planned 2026-08-12, not yet started)*

## Primary Goal

**Let players specialize/upgrade cards they've collected during a run (Wolf → Wolf Mage-style choices).**

## Success Criteria

By the end of this sprint, we should have:

1. [ ] Card specialization/upgrade system functional (Story 032)
2. [ ] Specialization choices surfaced at appropriate points in the run (post-story-branch, per the original
      design)

## Key Focus Areas

### 1. Data Model for Upgrades
A card needs to be able to transform into a themed variant (different stats/abilities) while remaining
recognizably "the same card" for deck-tracking purposes.

### 2. Presentation
Specialization choices should feel distinct from regular card-pack rewards — they're about deepening a card you
already have, not adding a new one.

## Non-Goals (Out of Scope)

- New base cards or abilities (that's Sprint 09/10 content work)
- Deck-mixing UX between the two types (Sprint 14 — related but separate)

## Definition of Done for Sprint

- [ ] A specialization choice presented mid-run correctly transforms the target card and updates the deck
